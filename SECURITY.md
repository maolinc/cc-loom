# Security Policy

## Supported versions

Until the first stable release, security fixes are provided on the latest
commit of the default branch only.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include secrets,
tokens, private repository URLs, or user data in a report. Use GitHub's private
vulnerability reporting for this repository. Repository maintainers must
enable that feature before the repository is made public.

Include the affected version or commit, impact, reproduction steps, and any
suggested mitigation. Test only systems and data you are authorized to access.

We will acknowledge a report, investigate it privately, and coordinate a fix
and disclosure before publishing details.
